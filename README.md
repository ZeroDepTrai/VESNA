# VESNA

A standalone Drawing API UI library with Crimson Rose styling, bento cards, configuration profiles, and native-chat-safe input.

Execute `Vesna.luau` to open the bundled demo. The title logo loads from this repository; `assets/vesna_logo.png` is its local fallback.

The UI requires an executor providing Drawing and Roblox client services. Text uses Font 0. Window size: 695 × 452. RightControl toggles visibility. The close button opens an unload confirmation.

Configuration files use `VesnaConfigs/<GameId>/`. Existing Obsidian profiles may be copied into this folder. Native Roblox text entry suppresses library hotkeys.
